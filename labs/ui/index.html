Menu Dial

The six buttons remain in fixed positions. Drag your finger around the center, use arrows, or tap a station to change the selection. As you advance, the next page of choices fills the same stations. No spinning wheel animation.

Editor & module export

Use the standalone JavaScript class from src/mechanics/fixed-menu-dial.js. It has no framework dependency or MobiLab globals. Bring your own data and selection callback.

↓ Download independent JS module 
import { FixedMenuDial } from "./fixed-menu-dial.js";
const dial = new FixedMenuDial({
  root: document.querySelector("#dial"),
  items: ["Home", "Projects", "Settings"],
  visible: 6,
  onChange: (item, index) => console.log(item, index)
});
