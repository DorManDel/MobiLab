PHOTO SPACE —BLINK FRAME IDLEANCHORS NORMALIZED
Photo / JSON tools

Yellow dots = drag the eye. Purple (outside eye) = width / angle. Cyan (above eye) = height. Tap “Edit” to adjust; “Zoom” to fine-tune.

01 / Eye anchors

Drag an eye marker on the photo, or use the controls below. The selected eye stays centered when zoomed.

Fine position
Anchors use native-image normalized coordinates (0–1). They do not depend on CSS pixels, zoom, crop, orientation, or browser refresh. Show anchors and edit mode are independent.

02 / Blink behavior

Blinking uses a short animation burst and a sleeping timer—not an always-running render loop. Auto-blink pauses when the tab/portrait is hidden.

03 / Motion & composition

This is only a prism-style sheen, not your full Prism Tilt shader. The photo + eyelids + highlights share one motion parent.

04 / Experiment controls

Auto-saves on this browser. Export JSON for a portable, Git-friendly config. Uploaded photos stay on your device and are not stored or transmitted by this lab.

ENGINE 01 / Coordinate model

Anchor on the source image

Eye positions are ratios in the original photo, not offsets from the viewport. The renderer compensates for cover/contain crop offsets.

ENGINE 02 / Layer stack

One shared transform

Photo, canvas eyelids and prism placeholder live inside a single moving layer. Future motion cannot separate the eyelids from the face.

ENGINE 03 / Runtime budget

Animate only when needed

Only eyelid masks redraw during a blink. Pointer transforms remain CSS-composited; idle portraits have no continuous animation frame loop.
