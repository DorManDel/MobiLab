MobiLab / Download Utilities

Paste. Queue. Launch.

Organize links from YouTube and other yt-dlp-supported websites, generate safe local commands, and prepare a Windows download launcher. Nothing is downloaded by this web page.

01 · Quick Mode

Run the downloaded script in PowerShell on your own Windows PC. It checks for yt-dlp and FFmpeg and uses your download archive to skip completed media. The browser cannot execute local programs.

Manual mode · copy exact commands

For advanced use: select a format and copy the PowerShell command. URLs are passed individually to yt-dlp.



  1. Install yt-dlp and FFmpeg on Windows and ensure both are on PATH.
  2. Paste URLs and press Add to queue.
  3. Copy the commands into PowerShell, or download and run the launcher from Quick Mode.
  4. Keep downloaded.txt in the output folder to avoid downloading media twice.




About browser limitations and supported URLs
This interface recognizes HTTP(S) links, labels common platforms, and stores your pending queue in this browser. Actual site support and playlist availability depend on the installed yt-dlp version and the source website. URL recognition here is not an online availability check. Video and playlist content is downloaded only by your local tools.

    Windows setup · first time only
    1. Install Python/yt-dlp and FFmpeg. The launcher expects executable tools on PATH.
    2. Use winget install yt-dlp.yt-dlp if that package is available, and winget install Gyan.FFmpeg for FFmpeg.
    3. Open a fresh PowerShell window and check yt-dlp --version and ffmpeg -version.
    4. Use the generated launcher for subsequent batches. Keep your existing archive file.
