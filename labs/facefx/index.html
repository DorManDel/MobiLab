Windows setup commands & connection help

After downloading the updated MobiLab source with the PC server, open PowerShell in the repository root:

py -3.11 -m venv facefx-server\.venv
.\facefx-server\.venv\Scripts\python.exe -m pip install -r facefx-server\requirements.txt
.\facefx-server\.venv\Scripts\python.exe facefx-server\server.py

Copy the session token printed in PowerShell. On another terminal, after signing in to Tailscale on your PC and phone:

tailscale serve 8080

Copy the HTTPS address shown by Tailscale above. Start with Debug, then configure a licensed ONNX swap model to enable AI Face Swap. No model weights or personal photographs belong in this public repository.
