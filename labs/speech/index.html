ENGINE NOTES

What's real and what's next?

  • Engine comparison: MyMemory, desktop-only Chrome Translator and an optional user-controlled HTTPS LibreTranslate-compatible server can translate the same finalized text. One microphone recognizer still supplies that text; these are translation engines, not independent STT models. Provider quality cannot be inferred from agreement alone.
  • Speech recognition: Web Speech API on supporting browsers, typically cloud-backed; Android may stop listening after pauses. The lab attempts safe restarts while you keep the mic enabled.
  • Translation: MyMemory public API has anonymous limits; only final phrases are submitted. Requests are placed in a bounded queue, canceled on Stop, and failures remain visible. A separate custom server can be used with explicit opt-in.
  • Automatic spoken-language detection: Not implemented in this version. Later: audio-language-ID + Whisper or a comparable multilingual recognizer.
  • Future inputs: File upload, video playback, permitted desktop tab audio, native Android media capture, OCR translation and a keyboard integration each require their own adapters.
  • Model comparison: Benchmark Whisper / device recognition / cloud STT on the same consented dataset, comparing WER, latency, battery and privacy; don't mistake model-generated guesses for ground truth.

Open over HTTPS or localhost for microphone access. Test in full Chrome or Samsung Internet, not an in-app embedded browser.
